Employee Penalty Management

Seamlessly manage employee penalties and integrate with Odoo Payroll!

Key Features

Define Penalty Types

Create and configure various types of penalties with fixed default amounts and currencies to ensure consistency across the organization.

Record Employee Penalties

Assign specific penalties to employees with a formal approval workflow (Draft, Approved, Rejected, Cancelled, Discounted).

Seamless Payroll Integration

Approved penalties are automatically fetched and deducted when generating an employee's payslip for the corresponding month.

Automated State Management

When a payslip is paid, the system automatically marks the associated penalty as "Discounted", keeping your records up to date.

How it works

1. Go to Penalty Types and create a new penalty type with a fixed deduction amount.

2. Create a new Employee Penalty, select the employee, the penalty type, and set the penalty date. Approve the penalty.

3. Generate a Payslip for the employee. The system automatically fetches approved penalties for that month and creates deduction input lines!
